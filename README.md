# Desuwa 🌸

A web application designed to help users learn and practice Japanese! 

## Features

- **Kana Chart**: Learn and review Hiragana and Katakana characters.
- **Vocabulary**: Practice and expand your Japanese vocabulary.
- **Dictionary**: Look up Japanese words and their meanings quickly.

## Tech Stack

- **React** for the UI
- **React Router** for navigation
- **Vite** for fast, modern web development

## Getting Started

First, ensure you have Node.js installed. Then, clone the repository and install the dependencies:

```bash
git clone https://github.com/AYG45/Desuwa.git
cd Desuwa
npm install
```

To run the development server:

```bash
npm run dev
```

Then, open your browser and navigate to the URL provided by Vite (usually `http://localhost:5173`) to view the application.

## Building for Production

To build the application for production, run:

```bash
npm run build
```

This will generate a `dist` directory with the optimized production-ready files.
